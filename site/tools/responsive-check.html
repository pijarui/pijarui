Responsive check — real viewports

Why this file exists. An earlier version of this check set body.style.width and excluded <pre> from the results. Both were wrong: resizing the body does not re-evaluate media queries, so lg: breakpoints stayed active and the single-column layout was never tested — and excluding <pre> skipped exactly the element that overflowed. A real iPhone caught a 70px horizontal scroll that this check reported as clean. An iframe has its own viewport, so breakpoints behave properly, and nothing is excluded here: the pass condition is the document's own scrollWidth.
